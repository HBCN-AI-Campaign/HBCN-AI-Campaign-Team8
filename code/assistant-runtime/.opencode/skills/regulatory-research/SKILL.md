# 法规与规则研究

调用知识库检索相关业务规则和法规资料，逐项给出来源标题、原文摘录或摘要、适用日期（若资料提供）以及与当前问题的关系。

不得根据记忆补写法规条文、条号、生效状态或司法辖区适用结论。没有可引用来源时明确说明检索证据不足，并请有权限审核人员确认现行法规。
