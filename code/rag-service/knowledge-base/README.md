# 境外 / 跨境贷款知识库（HBCN Team 8）

本目录存放「境外贷款单据智能审核平台」的**外部法规与银行公开资料**知识库原始文件，
供 RAG 服务（[`../app`](../app) 与本地引擎 `law` 范围）入库检索使用。

## 目录结构

```
knowledge-base/
├── README.md            # 本说明
├── catalog.json         # 资料清单索引（标题 / 文号 / 来源 URL / 下载方式 / 标签）
└── docs/
    ├── cn/              # 中国法律法规（25 份）：每份一个 PDF + 一份纯文本 .txt
    ├── intl/            # 境外法律法规（新加坡 2 份 PDF）
    └── hsbc/            # 汇丰银行公开网页（5 个 HTML + 纯文本 .txt）
```

- `*.pdf`：可直接阅读的文档（官方 PDF 原文，或用本机 Edge 无头浏览器把官方网页渲染成的 PDF）。
- `*.txt`：从原文提取的纯文本，供 RAG 切片与向量化直接使用（已去除 HTML 标签、统一 UTF-8）。
- `*.html`（仅 hsbc/）：汇丰网页的原始 HTML 存档，保留原始链接与结构。
- 每份资料的**来源 URL、文号、发布机构**都记录在 `catalog.json`。

## 下载方式（可复现）

1. 中文法规：直接 `GET` 官方网页（UTF-8 / GBK）或官方 PDF 附件；
2. 官方只有 HTML 的，用本机 Edge 无头模式 `--headless --print-to-pdf` 渲染成 PDF，
   并从同一 HTML 提取纯文本 `.txt`；
3. 境外法例：直接下载官方 PDF（如新加坡法例库的 `?ViewType=Pdf`）。

重跑下载（在 `code/rag-service` 目录下）：

```powershell
.venv\Scripts\python scripts\fetch_knowledge_base.py --pdf
```

脚本读取 `catalog.json` 逐条下载；已存在的文件自动跳过（幂等）。

## 入库到 RAG（检索使用）

本地引擎已开放 `law`（法规）检索范围。把 `docs/cn/*.txt`、`docs/hsbc/*.txt` 等
文本文件通过 `POST /api/v1/documents`（scope=law）或本地引擎入库后，即可在
`http://127.0.0.1:8010/ui/` 检索到这些法规与汇丰资料。
