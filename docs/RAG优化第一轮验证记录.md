# RAG 优化第一轮验证记录

> 对应优化规划 v3、持续执行台账。记录源码验证，不代表共享环境已部署，也不代表全部需求通过验收。

## 范围与结果

本轮覆盖 R01–R03 查询规划基础、R04 查询族归并基础、R07 受控循环及 R17 纯证据接口。保留用户精确问题，生成通用与英文表达；数字/币种校验拒绝新增事实；信息不明先澄清。复用 LangChain PostgreSQL 的 RRF，对查询族归一化，避免堆叠同义词重复投票。它尚不是词法/向量混合检索或独立 reranker。

LangGraph 保留跨轮候选，允许空召回后补检索，限制查询数、轮次与时间预算；重复查询、无新增证据、格式异常和预算耗尽均有停止原因。新增鉴权 POST `/api/v1/retrievals` 返回原文、缺口、充分性状态与来源，主审核 Agent 自行生成答案，避免双重生成。预算不足仍返回部分支持证据，但不得声称充分。

## 复审发现与修复

1. 实际模型返回多个中文同义词时挤掉英文表达：现预留通用与跨语言查询位置，新增回归。
2. 模型同时声称充分并列出缺口：现按不充分处理，保留相关证据。
3. 空召回、重复查询和无新增证据可能浪费调用：增加恢复与显式停止测试。
4. 多轮覆盖需要累计依据：保留候选池，避免后一轮覆盖前轮结果。
5. 输出预算不足分支丢失已选支持证据：修复为返回部分证据与预算缺口，新增回归。
6. 真实语料路径未配置导致原测试失败：拆分可移植夹具与显式外部语料测试；未将跳过包装为通过。

## 未完成验收与下一轮

- 尚无独立保留题集，不报告 Recall、nDCG、依据支持率达标。
- 当前仅多查询向量归并；中文词法混合、跨源配额、原文补取和独立重排待实现。
- 法宝适配器、网页可信上下文、历史案例治理与任务权限尚未完成。
- 数字/币种防护为词面校验，尚非完整金额语义证明；中文大写金额、单位换算和确定性计算另行实现。
- 引用校验目前检查编号，未验证每个结论是否被原文支持；runtime 单片段上下文仍可能截断，后续必须解决覆盖与截断可见性。
- 时间预算为阶段检查与 HTTP 超时，不是数据库查询的即时取消保证。
- 资源、真实端到端时延与费用、灰度/回滚尚未验收。持续目标保持执行中，下一轮优先检索质量与多源契约。
