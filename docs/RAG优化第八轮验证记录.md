# RAG 优化第八轮：工作台契约与浏览器复审

> R08/R09/R12/R15/R16/R17 部分实现；2026-10-22。仍按 v3 规划执行，未完成真实业务质量、任务权限或共享部署验收。

## 实现与复审修复

React 工作台移除固定答复、模拟来源/页数及打字计时器，复用 Ant Design X 1.6.1 的 Bubble、Sender、ThoughtChain、XStream。真实同源 Cookie、问答 SSE、仅证据检索、文档列表、解析原文及入库状态接入同一服务端契约。用途、法规条件、缺口和来源状态显式展示，RRF 分数不显示为置信概率。各消息持有自己的引用，打开旧消息不会误用最新消息来源。服务端凭证不进入浏览器配置或存储。

审核发现并修复：

1. SSE 组件保留冒号后空格，事件名需归一；异常事件、重复 result、提前断流不能当成成功。读取器在结束/失败时取消释放。
2. 本案用途即使被规划器识别为内部规则，也必须取得法规证据并通过法规门禁，不能借意图分类绕过。
3. 新 UI 与旧进程可能只更新了静态资源；新增 workbench_contract_version，不匹配时阻断请求。此标记不表示模型/索引/MCP 健康。
4. 原文读取只允许规范本地 UUID 路径，响应文档 ID 必须与请求一致；校验页码、正文与原件可用状态，无原件不承诺可打开。外链限无凭证 HTTPS，正文纯文本渲染。
5. 异常 JSON 和 HTTP 错误统一提示，避免展示响应体或内部细节。停止按钮只声明浏览器停止接收，未冒充服务端取消。
6. 初始安装发现旧测试分支漏洞，升级 Vitest 至 4.1.12，按新版本使用 client 依赖预构建。没有弱化测试断言掩盖兼容错误。

规划补充 T09/T16 的四层验收证据：组件/接口机制、真实浏览器与 HTTP/SSE 的合成依赖契约、真实模型/索引/MCP 业务闭环、共享部署与任务 ACL。前层不能替代后层；补充是细化标准，未降低原要求。同时修正“法宝尚未接线”等过时描述，当前与目标架构、四图源文件及导出物同步。
