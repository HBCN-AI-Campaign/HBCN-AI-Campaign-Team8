# RAG 优化第十五轮验证记录

> 日期：2026-10-22。服务版本 `0.5.0`，HTTP 契约 `1.3.0`。本记录只陈述本轮源码与合成依赖测试，不代表真实网页采集、生产授权、云部署或检索质量已验收。

## 本轮范围

为独立 RAG HTTP 模块增加请求内网页文本快照来源。授权调用方传入实际页面/选区文本、HTTPS URL、采集时间、精确范围、语言及处理授权；服务不代抓任意 URL，不持久化快照。新增来源默认关闭，需独立 `X-Web-Context-Key` 主体、reader scope、精确域名白名单及有效期配置。

知识库、北大法宝有序候选与网页无序上下文进入统一证据检查和专用 reranker。网页不制造 RRF 名次或票数，来源标明调用方提供且真实性未核实；选中的网页不能单独放行本案法规判断。模型调用前、评估与最终返回前重新检查授权、时效和正文绑定，撤权或内容被改写时阻止答复返回。`/query` 旧路径保持兼容；增强检索、引用问答 JSON/SSE 可显式选择网页快照。

接口与示例见[HTTP 契约](../code/rag-service/API_CONTRACT.md)、[网页上下文契约](RAG网页上下文接入契约.md)及[模块总览](../code/rag-service/README.md)。目标架构源图见[网页上下文流程](diagrams/rag-web-context.mmd)和总览中更新后的 RAG 架构。

- 前端 `npm test -- --run`：17 项通过；`tsc -b --pretty false` 与 Vite production build 通过。
- Playwright + 隔离 FastAPI synthetic upstream：桌面与窄视口契约烟测通过，验证 React 对网页来源与未核实提示的展示。未接真实浏览器采集器、生产 API、模型或法宝。
- 隔离 uvicorn smoke：`/health`、`/docs`、OpenAPI 网页快照 endpoints、契约版本和未授权拒绝符合预期。
- `python scripts/export-openapi.py --check` 与 Mermaid 源图检查通过；`git diff --check` 在本轮最终变更后重跑。

## 复审结论与未完成项

复审发现长标题等来源元数据可能挤掉未核实提示；已把警示前置到模型来源说明并添加回归断言。复审也确认网页只作为不带 RRF 名次的候选上下文进入重排；完整性未知、外链内容变化、法规身份和效力未经核实都显式呈现。

本轮不验证采集者是否真正获得用户授权，也不能仅凭请求中的 `processing_authorized=true` 建立主站身份或案件 ACL。主站必须在可信后端完成用户/任务授权、按白名单采集、剔除页面脚本/导航噪声并将授权主体映射至独立 RAG 身份；不能向浏览器暴露服务 Token 或网页上下文 key。真实网页提示注入、跨语言检索收益、法宝正文补取、reranker 模型收益和网页引用业务适用性需进入授权语料/金标评测。

Linux/systemd 与 Docker 交接模板已记录配置，不在本机做部署；本轮未验证目标云网络、Secret、持久盘、并发、吞吐、费用、主站 ACL 或回滚。部署团队需使用获批云资源和模型 API 按规划质量门槛测试，不因现有 ECS 配置缩小目标。原先模块的质量重检、撤回屏障和回滚兼容要求仍有效。

下一轮优先把主站实际身份/任务权限以服务端可信上下文接到多源请求，并基于批准的网页/法宝/知识库测试集评估来源并集、跨源去重、排序与结论支持；之后按失败归因修订规划再实施。详情以[持续优化规划](Agentic-RAG优化规划.md)和[执行台账](RAG持续优化执行台账.md)为准。
