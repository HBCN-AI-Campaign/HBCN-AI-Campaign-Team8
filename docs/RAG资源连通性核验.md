## 网络和安全事项

- 数据库应从 ECS 所在私有网络访问；本机开发可以使用临时 SSH 隧道，不应为了调试直接开放数据库公网访问。
- 本次强制 SSL 连接被数据库拒绝，提示服务器不支持 SSL；随后通过 SSH 隧道使用兼容连接模式完成验证，数据库会话 `ssl=false`。SSH 加密仅覆盖本机到 ECS，ECS 到 RDS 的链路本次未启用数据库 TLS，正式使用前需与资源管理员确认。
- ECS SSH 主机密钥为首次见到，本次没有独立的组织方指纹用于比对，也没有写入本机持久化 `known_hosts`；正式长期接入需核对主机指纹。
