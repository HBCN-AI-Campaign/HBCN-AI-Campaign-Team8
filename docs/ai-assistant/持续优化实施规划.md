## 第 46 轮：保护保存中的技能编辑并适配窄屏

**审核人员遇到的问题：**网络较慢时，技能保存尚未返回，仍可尝试按 Escape、点遮罩或关闭按钮离开，造成保存结果不确定；手机屏幕较矮或出现版本冲突信息时，编辑正文和底部操作需要争抢空间。

```mermaid
sequenceDiagram
  actor R as 审核人员
  participant M as 技能编辑弹窗
  participant API as 个人技能 API
  R->>M: 修改技能并保存
  M->>M: 显示保存状态，锁定取消/关闭/Escape/遮罩
  M->>API: 提交当前 revision
  alt 保存成功
    API-->>M: 新版本
    M-->>R: 关闭弹窗并提示已保存
  else 保存失败或版本冲突
    API-->>M: 错误 / 最新 revision
    M-->>R: 保留本地修改并显示可比较信息
```

## 第 43 轮：活动会话短暂断线后继续恢复

**审核人员遇到的问题：**正在运行的私有审核会话每 1.8 秒同步一次。网络抖动或服务暂时返回 5xx 时，旧逻辑会清空已显示消息并停止活动运行轮询；审核人可能误以为任务消失，甚至再次提问。

```mermaid
sequenceDiagram
  actor R as 审核人员
  participant UI as 慧眼助手
  participant API as 助手会话 API
  participant E as 运行事件 API
  R->>UI: 重新打开正在运行的会话
  UI->>API: 读取会话和 active_run
  API-->>UI: 返回运行中
  loop 运行同步
    UI->>API: 读取会话状态
    API--x UI: 暂时 503 / 网络中断
    UI-->>R: 保留消息和运行状态，提示正在重试
    UI->>API: 下一周期重试
  end
  API-->>UI: 运行已完成
  UI->>E: 回放本轮事件
  UI-->>R: 恢复最终答复和依据
```

- **修正：**API 错误保留 HTTP 状态码；网络/5xx 暂时失败保留消息、活动运行及事件游标，继续轮询并提示不要重复发送。成功同步后清除连接提示；401/403/404 清空受保护材料、技能和运行态，并离开失效会话。
- **验收：**活动恢复/撤权状态和助手 API 两个测试文件 **10/10**；覆盖 503 后重试并恢复完成答复、403 后立即清理上下文、403 状态保留。Vite 生产构建通过，助手 JS **213.60 KB / gzip 72.76 KB**。
- **验收：**状态/API 两个定向测试文件 **10/10**；浏览器 loopback 流程 **12/12**，真实页面依次读到活动会话、503 恢复提示、已完成答复；既有运行请求计数不增加，临时会话清理完成。模型/RAG 调用 **0**、浏览器异常 **0**。Vite 生产构建通过；全站类型检查仍受主站缺少 `dayjs` 阻断。整组前端 **44/44** 为本轮改动前基线。
- **限制：**这是本地浏览器和合成 503 响应验收，不等同于汇丰目标环境的真实断网、代理恢复或多标签联测。

## 已核对的取舍

- 上游组件继续用 [Ant Design X](https://github.com/ant-design/x)；成员/邀请借鉴 [LibreChat ACL](https://www.librechat.ai/docs/features/access_control) 的资源权限思路。只写本项目业务适配，不部署第二套认证或聊天系统。
- 模型执行继续用 [OpenCode](https://github.com/anomalyco/opencode)；锁定版本先通过现有回归，不为“最新”盲目升级。
- 当前主站任务权限是角色规则，尚无独立细粒度任务 ACL。助手必须复用并如实说明这一边界，不能声称完成了全平台 ACL。
- 新表独立，避免改队友现有任务表/RAG；旧会话默认私有，协作只向同样有任务访问权的审核人员开放。
- 先用数据库事件和有游标的增量读取完成可恢复协作；不用 CRDT 修改聊天历史。多实例/持久队列上线前单独验收。
- 正文目前是完整答复后分段回显。真实 token 流必须先核对 SDK 的事件与输出安全，不能把动画叫作真实推理。
