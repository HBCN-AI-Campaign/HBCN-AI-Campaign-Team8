当前基线为已有的 PaddleOCR HTTP 服务；OCR 引擎、语义抽取和视觉复核分别有接口，可独立替换。所有代码在 `lfc` 集成；不向 `main` 写入或合并。原件与原始识别结果保留本地受控目录，不入 Git。

文件名不明确时，创建任务和补件均可按原件选择类别并填写依据，重新解析产生新凭据；类别、依据、人员和时间进入只读审计。未知类别不会空字段继续创建。该回退为经办人选择，不计作自动分类准确率；实际异步API回放已通过，最新验证见验收记录。
