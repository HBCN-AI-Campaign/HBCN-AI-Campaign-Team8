## 2026-10-23：受限样本质量诊断基线

质量指标分层记录PDF渲染、OCR请求/空响应/块与框、字段Schema映射、规范化与证据、页码/框定位、正确自动接纳覆盖；自动接纳精度与自动覆盖率分别计算，核心错误接纳单独列出。聚合报告不写文件名、正文、OCR块、字段值或原始响应。第八套现有金标`set8/1.1`含7份/54页身份信息、39个核心标量、10个计量事实、2个真实选项和5个保护事实，但本隔离工作树未带对应原件及OCR/模型缓存，当前不能重算真实指标。

外部业务审核复放反馈21份PDF/174个字段槽位中仅4项同时非空且有定位（2.3%覆盖信号）；该材料与逐页阶段产物未在本工作树提供，不能归因或当准确率。仓库合成样例`commercial_contract.pdf`单页受限探针：渲染1191×1684、OCR返回68块/1319非空字符，68/68框在页范围内，OCR分数0.9051–1.0。该结果仅验证一页样例上的PDF渲染和OCR协议/像素框范围；无字段金标，不计字段正确率、框准确率或真实业务效果。其余大扫描样例未运行。

回归补充：OCR空/纯空白响应稳定报`OCR_NO_TEXT`；第二页OCR像素框应映射至第2页并保持归一化坐标；多模态返回未注册字段键时报`SEMANTIC_UNKNOWN_FIELD_KEY`，非法结构报`SEMANTIC_INVALID_FIELD`，诊断仅保留错误码、不保留响应值，且文档不能报ready；越界的PDF原生文本框不能成为字段位置；跨页标量不能伪装成第一页单框；页诊断返回尺寸、块数、字符数、分数桶与合法框计数，但不返回正文。当前解析定向套件195项通过、1项因业务审核审计集成条件跳过；全量后端313项通过、同1项跳过。详情和限制见[验收记录](验收记录.md)。

## 指标与门槛

- 自动接纳准确率：标注子集中正确接纳数/接纳数；没有接纳值时为未定义，不能填100%。
- 自动覆盖率：正确接纳数/全部标注事实。漏提取、服务错误和保守转人工均计入未覆盖。
- 错误自动接纳：必须逐项列出；核心金额、币种、日期、账号出现错误接纳即不通过。
- 歧义关口：FOL主体/额度和付款日期不确定时必须空值并待核实，不能只靠不输出文件计为通过。
- 原文依据：页码及框合法只代表可定位的初检，仍需原图验证实际覆盖字段值。
- 选项/表格：选中、未选、删除、歧义分开统计；行列和值、单位、证据均正确才算表格正确。

确定性回归包含金额精度、日期歧义、低OCR分数、删除/未选/未知标记、跨页候选冲突、虚构块ID、表格单元格幻觉、无依据列表项、API错误与截断，以及凭据归属、原件哈希、人工更正审计和入表后变更失效。它们验证程序边界，不能替代真实图像识别测试。
