## 5. 联合验收用例

| ID | 场景与操作 | 必须看到的结果 | 验收双方 |
|---|---|---|---|
| A01 | 上传文本PDF/扫描件/跨页表格 | 字段与原件一致，未知不补造，低置信度可复核，定位正确 | 解析组＋罗检 |
| A02 | 同币种金额不等与币种混杂 | 确定性差异准确；AI原样引用数值/币种，缺事实先澄清 | 罗检＋专项组 |
| A03 | 异常→慧眼问“如何核查” | 自动关联正确任务，真实业务规则命中，可打开原文；不混用项目设计 | 刘范聪＋罗检 |
| A04 | 断开RAG或MCP，或命中空正文 | UI清楚说明缺哪条来源；不显示“法规已核验” | 刘范聪＋专项组 |
| A05 | 一条法规专项，输出JSON非法或引用越界 | 输出校验拒绝；需人工/不可用，不写通过 | 刘范聪＋吴杨 |
| A06 | 两经办人交叉读写任务、补件、下载、聊天历史 | 全路径拒绝；服务Token不能绕过用户任务范围 | 罗检＋刘范聪 |
| A07 | 双击启动/请求重发/同key不同payload | 同请求复用run；冲突409；不重复外部收费或处置 | 罗检＋部署组 |
| A08 | 人工处置时模拟HTTP500/版本冲突 | 保持待处置，UI不放行、不显示已通过 | 罗检＋专项组 |
| A09 | 已挂起后刷新、SSE断连再连 | pending仍在，按seq回放，无重复模型调用；轮询可恢复 | 罗检＋刘范聪 |
| A10 | run进行中更正金额/补件或重跑规则 | 新快照、旧run标stale，旧结果不能写入当前终审 | 罗检＋解析/专项组 |
| A11 | 未决阻断项或保留异常时点complete | 后端拒绝；仅审核人有效处置且满足业务条件才完成 | 罗检＋诸葛 |
| A12 | 模型/worker超时、重启、容量429 | 有错误、trace及可控重试；未核验不pass，已完成确定性结果保留 | 部署组＋刘范聪 |
| A13 | 普通聊天/任务聊天/串换task_code | 不越权、不串任务；聊天状态与ReviewTask状态完全独立 | 刘范聪＋罗检 |
| A14 | 知识UI上传后检索与原文定位 | 真阶段、真答案/无答案、真引用，不固定来源；公网管理须JWT授权 | 刘范聪＋罗检 |

报告模板：`用例ID / commit与配置版本（无密钥） / 运行环境 / 脱敏输入 / 实际状态码与事件 / 期望 / 通过或失败 / 证据路径 / 复验人 / 限制`。模型评测与业务合规样例须由相应业务负责人确认，不能全部让同一个LLM自评。
